# Araf Protocol v3.0.0

Release notes for v3.0.0, covering the changes since v2.1 (about 280 commits). This is testnet software and has not
been externally audited. Do not use it with real funds.

## Highlights

- **Bleeding escrow V3 contracts.** `ArafEscrow` is rebuilt around parent orders, child trades, a 48-hour
  grace period and hourly bleeding of bonds and locked tokens, ending in `burnExpired` at hour 240.
- **Base Sepolia testnet deploy infrastructure.**
  - Frontend: `VITE_TARGET_CHAIN` flag for a Base Sepolia testnet build, with a testnet banner.
  - Backend: a testnet-only exception that lets the encryption key come from env instead of KMS. It applies
    only on chain 84532 and checks the chain through the RPC.
  - CI: deploy workflows you start with `gh workflow run` (see `docs/EN/DEPLOY_BASE_SEPOLIA.md`).
- **Easier setup.** `npm run setup` installs all three packages and runs `npm run init:env`, which creates
  the `.env` files.
- **Lint and CI.** Lint runs in CI for backend, frontend and contracts; `.nvmrc` pins Node 22.
- **Documentation.** New `docs/EN/ENV.md` lists every environment variable the code reads. The root README is
  rewritten as a project presentation.

## Contracts

- Reputation logic moved into `ArafReputationLib`; payouts and settlement offers into `ArafSettlementLib`.
  Errors are collected in `IArafEscrowErrors`; the ABI is preserved.
- `setRewards` can be called only once; transient intent handshake with the revenue vault; fixed durations are
  constants.
- Challenge flow: only the maker can call `challengeTrade`. After `MAKER_CHALLENGE_WINDOW` the maker ping
  lapses and the taker can use `pingMaker`.
- Storage packing for trades, orders and snapshots; measured gas baseline in `docs/GAS_BASELINE.md`.
- Rewards: 30-day epochs with a 7-day claim window, drift-safe outcome decoding, 6-decimal notional.
- Solhint config, explicit devDependencies and a test-token deploy script.

## Backend

- Env-KMS exception for Base Sepolia only (SEC-01), with RPC chain verification before any cache use.
- Event worker reads a block range with one `eth_getLogs` call; `logIndex` fix.
- Wallet age requirement set to 2 days.
- `init-env` script aligned with the JWT rules in `siwe.js`; `MONGODB_URI` helper and a single vault name.
- ESLint added as a devDependency; Node engines set to 22.

## Frontend

- `VITE_TARGET_CHAIN` testnet build and an info-toned testnet banner.
- Default GitHub link now points to `MyDemir/Araf-Protocol`.
- `.env.example` annotated with required and unread variables.

## Tooling & CI

- CI lint steps for backend, frontend and contracts; `npm run lint` at the root.
- `.github/workflows/deploy-base-sepolia.yml` and `deploy-runtime-base-sepolia.yml`, with JWT and WSS
  validation.
- New `release.yml` creates the GitHub release from `docs/releases/<tag>.md` when a `v*` tag is pushed.
- Root scripts: `setup`, `init:env`, `lint`, `test:all`, `test:abi-drift`.
- Package versions aligned to 3.0.0.

## Documentation

- Canonical architecture, API, deploy, PII, rewards, gas and mainnet documents re-aligned with the code (TR/EN).
- English `ENV` and `DEPLOY_BASE_SEPOLIA`; index in `docs/README.md`.
- Obsolete plans, audits and pitch files removed; `YAPILACAKLAR` renamed to `BACKLOG`.

## Known limitations

- No external security audit.
- Testnet only: the Base Sepolia deployment is in progress and no mainnet deployment exists. No public
  contract address or app URL is published in these notes.
- Open design questions (for example Tier 0 has no bond, tier promotion by trade count, penalties go to the
  treasury) are listed in `docs/EN/BACKLOG.md`.
- Mainnet readiness is tracked in `docs/TR/MAINNET_READINESS_CHECKLIST.md`.
